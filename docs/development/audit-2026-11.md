# NoisiQ codebase audit — November 2026

Snapshot audited: branch `NovemberCleaning` at `6628f21` (≈13k lines in `src/`, 808 tests).
Purpose: list everything that is hardcoded, broken, physically wrong, or not fit for a
public release, measured against the original vision (concept paper + README):

> Build or import **any** circuit, attach selectable noise models, and *see* how errors
> propagate — a step-by-step animation for small circuits, aggregate statistics and
> heatmaps for large ones — validated against algebraic identities and trusted simulators.

Every item marked **[verified]** was reproduced with a script against the snapshot.

---

## 1. Critical: the package cannot handle arbitrary circuits

| # | Finding | Where |
|---|---------|-------|
| 1.1 | **Gates are dispatched by name string.** Every backend, the backend selector, the Pauli-frame tracker, the heatmap propagation tables and the drawers contain `if name == 'H' ... elif name == 'CNOT'` chains. A user-built `Gate` (even a Clifford one) is rejected by the Stim backend **[verified]**, silently mis-drawn, or treated as the built-in gate if its name collides. | `backends/*.py`, `visualization/*` |
| 1.2 | **Gate angles are recovered by parsing the gate *name*.** `phase_gate(θ)` stores `"P(0.4488)"` (4 sig figs) and the Aer/Tsim backends parse the angle back out of the string → silent precision loss **[verified]**. `ry_gate` is not handled at all by Aer/Tsim. | `ir/gates.py`, `backends/qiskit_backend.py`, `backends/tsim_backend.py` |
| 1.3 | Missing standard gates: RX, U, SX, controlled-phase, CRZ, Toffoli (CCX), CSWAP, generic controlled-U, gate inverse. Users had to hand-decompose `cp` in every notebook. | `ir/gates.py` |
| 1.4 | No circuit-level utilities: `inverse()` (needed for uncomputing, e.g. "upside-down" GHZ), `compose`, `copy`, `depth`, `count_ops`, `measure_all`, `reset`, barriers. | `ir/circuit.py` |
| 1.5 | `Circuit.add_gate` accepts duplicate qubits, e.g. `CNOT(0, 0)` **[verified]**. | `ir/circuit.py` |
| 1.6 | Measurement only in the Z basis (`Measurement.__post_init__` raises otherwise) — blocks phase-flip codes (to-do list item). No standalone `reset`. | `ir/classical.py` |
| 1.7 | Conditional ops only support a hand-picked subset of gates through `_ConditionalBuilder` (no `s_dag`, `t`, rotations...). | `ir/circuit.py` |
| 1.8 | No ready-made algorithms; every notebook rebuilds GHZ/QFT/Grover/DJ by hand (to-do: "hard code common algorithms"). | — |

## 2. Critical: backends

| # | Finding | Where |
|---|---------|-------|
| 2.1 | **OOM at ~15 qubits.** `TrajectoryBackend` accumulates a full `4^n` density matrix every run (and hard-caps at 13 qubits) even when only per-qubit purities are needed **[verified]**. This is why "Stim isn't used in visuals" — the notebooks run the trajectory pass for the purity panel and fall back to smaller circuits. | `backends/trajectory_backend.py` |
| 2.2 | `StimTableauBackend` loops over shots in Python with one `stim.TableauSimulator` per shot, i.e. Stim's speed is never used. `ManyShotRunner` calls `run(n_shots=1)` once per shot. | `backends/pauli_frame.py`, `backends/many_shot_runner.py` |
| 2.3 | `QiskitAerBackend` **does not import** (`quantum_error` no longer exists in qiskit-aer) **[verified]**; it also crashes on measurements/conditionals, appends raw numpy arrays as gates, ignores Qiskit's little-endian qubit order, and is not exported. | `backends/qiskit_backend.py` |
| 2.4 | `TsimBackend` (bloqade-tsim) is a hard dependency, does not support measurements/conditionals, and the to-do list says to remove it. | `backends/tsim_backend.py`, `pyproject.toml` |
| 2.5 | The named Pauli channels (`DepolarizingChannel`, `BitFlipChannel`, …) are **not** subclasses of `PauliError`, so the Stim backend rejects them and the selector routes them to the slow trajectory backend **[verified]**. | `noise/pauli_channels.py`, `backends/backend_selector.py` |
| 2.6 | Three different code paths for the same physics (`run`, `run_paired`, `run_paired_shot`) with copy-pasted measurement logic; the "many-shot" result type is produced by two unrelated classes. No common result type. | `backends/*` |
| 2.7 | Noise is keyed by **position in `circuit.operations`** (`{op_index: channel}`). Any edit to the circuit (idle fill, DD insertion, reordering) silently shifts noise onto the wrong gates. | everywhere |
| 2.8 | Readout (SPAM) error is not modelled; `include_spam` adds a depolarizing error to the first/last *gate* instead. | `noise/hardware_noise.py` |

## 3. Physics / math errors

| # | Finding | Where |
|---|---------|-------|
| 3.1 | **T1 double-counted in idle noise.** `idle_kraus` applies `AmplitudeDamping(T1)` followed by `Dephasing(T2)`. Amplitude damping already decays coherences by `e^{-t/2T1}`, so total coherence decays as `e^{-t/2T1}·e^{-t/T2}` instead of `e^{-t/T2}` **[verified: 0.9827 vs 0.9876]**. Correct: dephase with `1/Tφ = 1/T2 − 1/(2T1)`. | `noise/idle_fill.py` |
| 3.2 | The Pauli-twirled idle channel uses `p_z = γ/4 + (1−e^{−2t/T2})/2`; the correct twirl is `p_z = (1−e^{−t/T2})/2 − γ/4`. Probabilities that overflow 1 are rescaled by a magic `0.99`. | `noise/idle_fill.py`, `noise/hardware_noise.py` |
| 3.3 | `HardwareProfile.to_noise_model(mode=...)` applies **either** T1 **or** T2 decoherence, never both **[verified]**. | `noise/hardware_noise.py` |
| 3.4 | "Spectator" error is applied to the gate's own qubits, not to spectators; `mcmr_crosstalk` is stored but never used; ZZ crosstalk is approximated as independent single-qubit Z. | `noise/hardware_noise.py` |
| 3.5 | `StochasticCoherentRotation` draws a fresh angle at **every** gate, so it is just a Pauli channel — not quasi-static noise. The dynamical-decoupling demo therefore cannot show genuine refocusing. Its twirl uses `sin²σ` instead of the exact `(1−e^{−2σ²})/2`. | `noise/coherent_errors.py` |
| 3.6 | Hahn-echo DD inserts a single `X` → **flips the logical state** of the idle qubit **[verified]**. | `suppression/dynamic_decoupling.py` |
| 3.7 | Docstrings name profiles that do not exist (`ibm_heron_r2`) **[verified]**. | `noise/hardware_noise.py` |

## 5. Tests

* 808 tests, but heavily coupled to internals and milestone names (`test_m4_*`, `test_phase4b_*`, `test_m8_*`). Many assert implementation details (private helpers, exact layout constants) rather than physics.
* No tests compare backends against each other on random circuits, no exact-density-matrix reference, and none exercise arbitrary user gates.
* Some tests codify bugs (e.g. the T1-double-counting formulas, the `0.99` rescaling).

## 6. Repository hygiene (what would ship to the public today)

* LaTeX build artifacts committed: `latex/*.aux, .bbl, .blg, .fdb_latexmk, .fls, .out, .synctex.gz`.
* 11 course "weekly" notebooks + 10 demo notebooks that copy-paste the same helper cells; several reference APIs that never existed (`nq.adapters.from_qiskit`, `nq.suppression.SuppressionPipeline`, `nq.visualization.animate_propagation`, `nq.backends.StimBackend`). Two notebooks carry 3.8 MB / 1.5 MB of embedded outputs.
* `scripts/run_tsim*.py`, root `theme.md`, `docs/documentation.ipynb` (a schedule table plus a note with a local absolute path).
* Unfinished research scaffold shipped as a public module: `protocols/mek_magic_state_distillation.py` (contains `_TODO_expand_…` stubs and a "SCAFFOLD ONLY" warning).
* README: placeholder badges (`<your-org>`), a quickstart that does not run (`circuit.add_noise`, `nq.visualize.propagation` do not exist), outdated roadmap.
* `pyproject.toml`: hard dependency on `bloqade-tsim`, `qiskit`, `ipywidgets`, `pylatexenc`; `pyright` config pointing at a WSL venv; CI tests only 3.10/3.11 and never lints.
* Untracked junk in the working tree: `bash.exe.stackdump`, `texput.log`.
